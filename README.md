# Keyflow - Typing Speed Test

A simple typing test made with HTML, CSS, and JavaScript.

## Run the website

1. Keep all five project files in the same folder.
2. Open `index.html` in a web browser.
3. Choose 15, 30, or 60 seconds and type the passage.
4. The timer starts with the first keystroke. Press **Esc** or click **Restart** to try again.

There is no install step, server, or internet connection needed. The browser saves the theme and personal best on this device.

## Change the project

- Change or add practice paragraphs in the `passages` list in `script.js`.
- Change the Light and Dark colors in `themes.css`.
- Change spacing and layout in `styles.css`.
- Change page text or controls in `index.html`.

## How scoring works

WPM means words per minute. Keyflow treats five correct characters as one word, then divides by the number of minutes in the test so far. Accuracy is the number of correct characters divided by all typed characters.
